# DEMO — คู่มือพรีเซนต์

เดโมนี้ใช้เล่าขั้นตอนทำงานของ AI Perfumery Engine ด้วยข้อมูลสมมติ อ่านวิธีเปิดใน [DEMO.md](DEMO.md) แล้วใช้ปุ่มเปลี่ยนภาษา TH/EN ตามผู้ฟัง

ทุกหน้ามี **คู่มือพรีเซนต์** ด้านบน บอกว่าหน้านี้คืออะไร ช่วยอะไร และสาธิตอย่างไรใน 3 ขั้นตอน เปิดหรือย่อได้ กราฟและการตรวจปฏิสัมพันธ์มี **ส่วนนี้ใช้ทำอะไร** ให้เปิดคำอธิบายเฉพาะเรื่องโดยไม่เปลี่ยนสูตร

## ลำดับแนะนำประมาณ 5 นาที

1. **ภาพรวม → คลังสูตร** — แนะนำว่าระบบเชื่อมงานสูตร งานแล็บ และหลักฐานเอกสาร เปิด Morning Reverie แล้วชี้เวอร์ชันที่บันทึกไว้
2. **พื้นที่สูตร** — ใช้ Formulator ปรับสองสัดส่วนแรกเป็น `35` และ `35` โดยคงอีกสองรายการ `20` และ `10` ยอดรวมยังเป็น 100% บันทึกเวอร์ชันพร้อมหมายเหตุ แล้วเปิดประวัติเพื่อแสดงว่าเวอร์ชันเดิมยังอยู่
3. **What-if → ประเมินผล** — ทดลองเปลี่ยนสองรายการแรกเป็น `30` และ `40` กดประเมินผล ชี้ข้อความ **ข้อมูลไม่เพียงพอ** และหลักฐานที่ขาด จากนั้นกด **ดูกราฟตัวอย่าง** เพื่ออธิบายหน้าตาการวิเคราะห์ เปิดคำอธิบายใต้แท็บที่ต้องการ แล้วยกเลิกการทดลองก่อนเปลี่ยนหน้า
4. **ข้อกำหนด อย. / IFRA** — กดปุ่มนี้ในหน้าสูตร หรือเปิดเมนู **ข้อกำหนดและเอกสาร** เปรียบเทียบแหล่งข้อกฎหมายกับมาตรฐานอุตสาหกรรม เปิด **เอกสาร IFRA อยู่ตรงไหน?** แล้วชี้คลังเอกสารและผลแยก TH / EU / US / ASEAN ผลยังเป็นข้อมูลไม่เพียงพอ
5. **พื้นที่แล็บ** — เลือกเวอร์ชันสูตร ล็อต และเครื่องมือ สร้างแบตช์จำลอง บันทึกค่าตัวอย่าง แล้วแสดงประวัติการชั่งซ้ำ อธิบายว่า NORMAL / WARN / BLOCK เป็นสถานการณ์หน้าจอที่เลือกไว้ ยังไม่มีเกณฑ์การชั่งที่อนุมัติ
6. **กลุ่มผู้ใช้** — เปิดเมนูบทบาทเพื่อแสดง Internal Team, SaaS Workspace และ Client Portal จากนั้นเปิดสิทธิ์ย่อยของ Internal Team กลุ่มภายนอกยังเป็นแผนงาน ส่วน Pending access เป็นสถานะบัญชี ลองบัญชีของฉันหรือบทสอนตามสมัครใจเพื่อจบการนำเสนอ

ถ้ากำลังแก้สูตรแล้วเปลี่ยนหน้า เดโมจะถามว่าจะเก็บการแก้ไขหรือยกเลิก ก่อนเริ่มรอบใหม่กด Reset demo; ข้อมูลทดลองกลับค่าเริ่มต้น แต่โหมดสว่าง/มืดยังคงตามที่เลือก

| กราฟตามเวลา | แสดงรูปแบบการเปลี่ยนแปลงข้ามลำดับตัวอย่าง | 3 เส้นคือเส้นตัวอย่าง 1–3 ไม่ได้กำหนดเป็น Top / Heart / Base; S0–S5 ไม่มีระยะเวลาจริง |
| ความไม่แน่นอน | อธิบายว่าผลที่มีหลักฐานต้องแสดงข้อจำกัดและที่มาของความไม่แน่นอนด้วย | ยังไม่มีนโยบายหรือข้อมูลวัดสำหรับคำนวณช่วง/สัดส่วน ไม่สร้างเปอร์เซ็นต์ขึ้นเอง |

| คู่เสริมกลิ่น / คู่กลบกลิ่น / กลุ่มวัตถุดิบ | แสดงตำแหน่งหน้าจอสำหรับอธิบายความสัมพันธ์เมื่อมีกฎที่รองรับ | คู่และกลุ่มสมมติคงที่ แยกจากสูตรที่เลือก ไม่ประเมินผลจริงและไม่ส่งเข้าผลประเมินหรือไฟล์สูตร |
| ผลประเมินวิทยาศาสตร์ · ตัวอย่างจำลอง | อ่านผลสมมติสามข้อพร้อมคำอธิบาย แล้วเปิด **ผลจำลองนี้มาจากไหน?** | MOCK report เป็นบทสาธิตคงที่ ไม่คำนวณจากสูตร ไม่มีคะแนนความมั่นใจ ขนาดปฏิสัมพันธ์ หรือเกณฑ์ความปลอดภัย ผลประเมินจริงแสดงแยกด้านล่าง |

## อย. / ASEAN / IFRA อยู่ตรงไหน

อยู่ในเมนู **ข้อกำหนดและเอกสาร** การ์ดด้านบนมีคำอธิบายและลิงก์ทางการ ปุ่ม **ข้อกำหนด อย. / IFRA** ในหน้าสูตรพาไปหน้าเดียวกัน

| แหล่ง | ใช้อธิบาย |
|---|---|
| [อย. ไทย — กฎหมายเครื่องสำอาง](https://cosmetic.fda.moph.go.th/interesting-law/category/cosmetic-laws/) | แหล่งข้อกฎหมายเครื่องสำอาง เช่น สารห้ามใช้ เงื่อนไขการใช้สาร และฉลาก |
| [ASEAN — กรอบกำกับเครื่องสำอาง](https://asean.org/agreement-on-the-asean-harmonized-cosmetic-regulatory-scheme-phnom-penh-2-september-2003/) | กรอบระดับภูมิภาค ต้องตรวจข้อกำหนดของประเทศและตลาดเป้าหมายด้วย |
| [IFRA Standards Library](https://ifrafragrance.org/standards-library) | มาตรฐานอุตสาหกรรมน้ำหอม แยกจากกฎหมายของประเทศ ดู [คำอธิบายมาตรฐาน](https://ifrafragrance.org/understanding-standards) |

**IFRA Certificate of Conformity:** ผู้ผลิตหรือผู้จัดหาส่วนผสมน้ำหอมเป็นผู้จัดทำสำหรับการใช้ที่ระบุ IFRA ไม่ได้ออกเอกสารนี้ และเอกสารไม่ทดแทนการประเมินความปลอดภัยหรือกฎหมายของประเทศ ตาม [คำอธิบายจาก IFRA](https://ifrafragrance.org/initiatives-positions/safe-use-fragrance-science/ifra-standards/certification-of-ifra-standards)

ในเดโม กด **จำลองเพิ่มเอกสาร → ประเภทเอกสาร → IFRA certificate of conformity** เอกสารประเภทนี้อ้างถึง SKU ใช้เฉพาะตัวอย่างที่ฝังอยู่ ไม่มีการรับไฟล์จริง การครบรายการเอกสารไม่ทำให้ผลกลายเป็นผ่านข้อกำหนด

ลิงก์เหล่านี้ใช้เปิดอ่านข้อมูลประกอบ ยังไม่ใช่ชุดกฎที่ระบบนำเข้าหรือประมวลผล ก่อนตรวจจริงต้องมีแหล่งข้อมูลและเวอร์ชันที่อนุมัติ หมวดผลิตภัณฑ์ และฐานผลิตภัณฑ์สำเร็จรวมการเจือจาง เดโมไม่ได้เลือกเกณฑ์ตัวเลขหรือประกาศว่าปลอดภัย
